# PushCount

> 에어팟으로 몸을 측정하고, 캐릭터가 나와 함께 운동한다.

에어팟 모션 센서만으로 운동을 자동 카운트하는 iOS 앱.
푸시업을 시작으로 맨몸운동, 나아가 러닝까지 확장합니다.

## 컨셉

**측정** — 에어팟 IMU로 동작을 감지하고 검증해 정확히 카운트합니다.
**분신** — 측정 데이터를 캐릭터 애니메이션에 실시간 연동합니다. 내가 푸시업을 하면 캐릭터도 같은 리듬으로 움직입니다.

운동 중 사용자는 바닥에 엎드려 있어 숫자를 읽을 수 없습니다. 캐릭터의 움직임은 초점 없이 주변시로 인지되므로, 캐릭터는 장식이 아니라 **운동 중 화면의 주된 정보 전달 수단**입니다.

## 디자인 방향

생동감 있고, 밝고, 긍정적으로.

- 캐릭터가 1순위, 숫자가 2순위
- 밝은 배경 기본, 채도 높은 다색 팔레트 (종목별 색상)
- 모션이 곧 UI — 캐릭터 애니메이션이 시각적 핵심
- 운동 중 화면은 정보 최소화, 캐릭터 + 사운드 + 햅틱으로 전달
- 사용자를 벌하지 않는다 (기록이 끊겨도 캐릭터는 계속 긍정적)

## 로드맵

1. **푸시업** — 자동 카운트, 캐릭터 연동, 기록 저장
2. **맨몸운동 확장** — 스쿼트, 런지, 버피 등
3. **러닝** — GPS + 에어팟 모션 결합

## 시작하기

```bash
mise install
mise x -- tuist install
mise x -- tuist generate
```

**요구사항** — AirPods Pro 이상, 실기기 필수(시뮬레이터 미지원), 동작 및 피트니스 권한
